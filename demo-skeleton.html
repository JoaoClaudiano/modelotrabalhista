🎨 Sistema de Skeleton Screen

Demonstração do sistema global de Skeleton Screen com Shimmer Effect usando apenas CSS Puro e JavaScript Vanilla

📋 Exemplo: Cards de Perfil

Demonstração de como aplicar o skeleton screen em cards de perfil contendo avatar circular, nome, descrição e email. Os elementos mantêm seu tamanho real para evitar Layout Shift (CLS).

💻 Como Usar

O sistema é extremamente simples de usar. Basta adicionar a classe .skeleton aos elementos que deseja exibir como loading state.

1. HTML com Classes Skeleton

<!-- Adicione a classe .skeleton aos elementos durante o loading --> <div class="profile-card"> <img class="profile-avatar skeleton skeleton-avatar" alt="Avatar"> <h3 class="profile-name skeleton skeleton-title">Nome</h3> <p class="profile-description skeleton skeleton-text">Descrição</p> </div>

2. JavaScript - Remover Skeleton

// Remover skeleton de elementos específicos hideSkeleton('.profile-avatar'); // Remover skeleton com delay hideSkeleton('.profile-name', 500); // Remover skeleton de todos os elementos hideAllSkeletons(); // Usar com carregamento assíncrono await loadWithSkeleton('.profile-card', async () => { const data = await fetch('/api/profile'); // Processar dados... });

3. Classes CSS Disponíveis

/* Classes base */ .skeleton /* Aplica o efeito shimmer */ .skeleton-loaded /* Transição de fade-in */ /* Classes utilitárias */ .skeleton-text /* Para linhas de texto */ .skeleton-title /* Para títulos */ .skeleton-avatar /* Para avatares circulares */ .skeleton-card /* Para cards */ .skeleton-button /* Para botões */ .skeleton-image /* Para imagens */
